## Наблюдения

- Ollama в контейнере на этом Mac даёт 4 токена/с на генерацию и 13 токенов/с на чтение промпта:
  Docker на macOS не имеет доступа к GPU. Та же модель на хосте — около 13 токенов/с и 130–300 токенов/с.
- `brew install ollama` на macOS 14 запускает сборку из исходников вместе с LLVM и Rust: готовых сборок
  Homebrew для этой версии macOS больше нет. Поэтому используется официальный бинарник с GitHub.
- Docker Desktop с лимитом памяти 8 ГБ вместе с Qwen 2.5 7B не помещается в 16 ГБ: система уходит в
  своп (до 11 ГБ на диске), ответы замедляются в 2–3 раза. Проекту в контейнерах хватает 3–4 ГБ —
  лимит стоит снизить в настройках Docker Desktop (Settings → Resources).
