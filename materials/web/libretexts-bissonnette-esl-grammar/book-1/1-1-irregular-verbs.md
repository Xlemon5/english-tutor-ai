# 1.1: Irregular Verbs

**Verbs**

There are two general types of verbs in English: Regular Verbs and Irregular Verbs.
Regular verbs end in **ED i**n their past form as well as in their past participle form. (Regular verbs that end in a consonant plus a Y change the Y to I and then add **ED**.) Irregular Verbs change forms in the past tense and in their past participle forms. Note the differences below.

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| Regular Verbs | | | Irregular Verbs | | |
| open | opened | open | go | went | gone |
| start | started | started | feel | felt | felt |
| type | typed | typed | dig | dug | dug |
| smoke | smoked | smoked | show | showed | shown |
| collect | collected | collected | fly | flew | flow |
