# English Grammar / Subject and Predicate / Direct and Indirect Objects

DIRECT OBJECT -It is the person or things that directly receives the action or effects of the verb.It answers the question what or whom

© What type - direct
®Whom type - indirect

Ex- He gave a necklace to his wife

Here necklace is using what - so it is direct object

And the wife is using whom - so it is indirect object
